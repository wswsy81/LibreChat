SEC-001 production regression red evidence
Date: 2026-07-18

Production symptom (read-only log inspection)
- A normal cached mingli MCP connection began returning `identity assertion expired` after the 60-second assertion window.
- LibreChat then logged ping failure, Streamable HTTP SSE Unauthorized, OAuth authentication handling for a non-OAuth server, three reconnect attempts, and `Stopping reconnection attempts`.
- No message content was inspected. User identifiers are intentionally omitted from this evidence file.

Static root cause
- `processMCPEnv()` replaces `{{LIBRECHAT_FUTURE_ENGINE_IDENTITY}}` while the cached connection is constructed.
- `MCPManager.callTool()` refreshes request headers only after `getUserConnection()` has already called `connection.isConnected()`.
- The liveness ping, SDK SSE recovery, and high-level transport rebuild therefore reuse the assertion baked into `MCPConnection.options` at construction time.
